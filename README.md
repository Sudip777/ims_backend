# Inventory Management System (IMS) – Backend API

A production-ready, enterprise-grade **Inventory Management System Backend** built entirely with **.NET 8 Web API** using clean architecture and modern best practices.


## Core Features

- Full **Product, Category, Supplier, Warehouse** management
- Multi-warehouse **Inventory** tracking with real-time stock levels
- **Sales & Purchase Orders** with automatic stock deduction/addition
- Complete **Inventory Transaction Audit Trail**
- JWT-based authentication + refresh tokens
- Role-based authorization (SuperAdmin, Manager, Staff, Supplier)
- API versioning (`/api/v1/`)
- Pagination, filtering, sorting & searching on all list endpoints
- Global exception handling with standardized error responses
- FluentValidation for request validation
- AutoMapper for clean DTO → Entity mapping
